Stratum Pre-release EMIT Critical Minerals L3

Working on the code

The environment, the shape of the test suite, the four tests that are not negotiable, and the mistakes that have already been made once.

1. Environment

pixi install
pixi run test                     # pytest
pixi run lint                     # ruff check src tests
pixi run python -m stratum.regrid # check the recorded regrid hash — section 4

The environment is pixi over conda-forge, not pip over PyPI, and ADR-0001 records why: GDAL, rasterio and netCDF4 need to agree about the same native libraries, and conda-forge is where that agreement is maintained.

Two editable installs, and both are load-bearing

stratum itself is editable, and so is vendor/SpectralUtil — the latter because a non-editable install of that upstream repository ships no subpackages, its pyproject.toml listing only the top-level package. That is also why spectral-util is absent from [project].dependencies: it has no PyPI release. The submodule pins the commit, and the doc links to SpectralUtil source are pinned to that same commit rather than to a branch.

Two synthetic worlds, and why there are two

HelperProducesUsed by
synthetic.pyIn-memory arrays behind a FakeReader and FakeStore. No NetCDF at all; sensor pixels sit exactly on tile cell centres so the KD-tree is deterministicResolve-level tests that want to isolate the algorithm from the format
synthetic_nc.pyReal, tiny NetCDF files shaped like EMIT L2B MIN + L1B OBSThe end-to-end and invariant tests, which have to exercise the real readers

Both exist because they answer different questions. A failure under synthetic.py is an algorithm bug; the same test passing there and failing under synthetic_nc.py points at the reader or the format. Keeping them separate is what makes that inference possible.

No fixture is a file in the repository

conftest.py resolves real granules from STRATUM_TRIAL_DATA or STRATUM_FIXTURE_URL and skips when they are absent. The suite therefore runs green on a clean checkout with no data. A test that needs real granules is marked trial_data; the one reference L2B granule under refs/ is git-ignored and its fixture skips when it is missing.

3. The non-negotiable tests

tests/test_invariants.py holds four tests that are not ordinary regression cover. Each one asserts a property the whole design rests on, and a failure in any of them means something architectural has broken, not that a number moved.

TestAssertsBreaks when
Seam equivalenceFour 25-cell blocks and one 50-cell block deliver bit-identical product bandsAnything makes a result depend on how work was divided — a halo that leaks, a per-block normalisation, an ordering that is not deterministic
Cache-key sensitivityA scorer change moves snapshot keys and leaves GLT keys aloneA term leaks into the wrong key — the failure mode that makes iteration expensive, and the one users notice last
Recorded regrid hashALGO_HASH matches both the current version and the current module contentsGeometry code changes without the version bump — see section 4
Lumping sensitivityTwo enumerations with the same ids and names but different lumping produce different snapshot keysClass resolution stops entering the key by its content — the subtlest of the four, because both runs look identical in every report
Fixing one of these by relaxing it is always wrong

They are chosen so that the only honest fix is in the code under test. If seam equivalence fails, block-wise and tile-wise really do disagree, and the product is wrong at block boundaries.

4. The recorded regrid hash

Geometry is the one thing the cache cannot check for itself. A GLT's key contains REGRID_ALGO_VERSION, an integer a human maintains — so a change to the KD-tree path that nobody remembered to version would silently reuse GLTs built by the old code.

The guard is a recorded content hash. module_content_hash hashes every .py in the package; ALGO_HASH beside them records the version and hash that were current when someone last looked. check_recorded_hash compares them and names which step was skipped.

# after changing anything under src/stratum/regrid/
pixi run python -m stratum.regrid            # check: does ALGO_HASH still match?

# if GLT output can differ, bump REGRID_ALGO_VERSION first, then:
pixi run python -m stratum.regrid --record   # rewrite ALGO_HASH

The decision the tool cannot make for you is whether output can differ. A comment change cannot; a tolerance change can. When unsure, bump: an unnecessary bump costs one rebuild, a missed one produces wrong geometry that looks cached and correct.

5. The tests that guard these pages

The site has no build step and must not acquire one — plain HTML, one stylesheet, one script, working from file:// as well as from Pages. Documentation accuracy is therefore maintained by tests rather than by generation.

TestAsserts
Code links point at the line they nameEvery <a class="src"> on the site carries a data-sym fragment of the line it claims, and the test re-reads the file. A drifted link fails the suite
The regex matches somethingA pattern that silently matched nothing would make every assertion above it vacuous
Every package is on the codebase mapA package added to src/ and documented nowhere. Link rot is caught by the test above; absence is not, because a page that omits something breaks no link
… and the map names nothing that is goneThe other direction: a module renamed or deleted while the map still cites it
The framework never imports the plugin packageNothing under src/stratum/ imports stratum_emit — the boundary the codebase map asserts, enforced rather than hoped for
The package graph is acyclicThe layer table stays true. A cycle names the two packages that formed it
Every Developer page is in the nav modeldata-page matches an id in PAGES and data-root is ../. Both fail silently in a browser, which is why a test is worth more than care

When a code link fails, repoint it; never loosen the assertion. A doc that links the wrong line is worse than one that links nothing at all.

After adding or moving a page there is one more check, because data-page and data-root fail silently when wrong:

python3 - <<'EOF'
import pathlib, re
root = pathlib.Path('docs')
for f in sorted(root.rglob('*.html')):
    for m in re.finditer(r'(?:href|src)="([^"#]+)"', f.read_text()):
        u = m.group(1)
        if u.startswith(('http', 'mailto:')): continue
        if not (f.parent / u.split('#')[0]).resolve().exists():
            print('BROKEN', f, u)
EOF

7. Footguns

Doing thisProducesInstead
Adding a term to a cache key without thinking about which artifact it belongs toEither too much rebuilding, or stale hits — and the second is silentPut it in the narrowest *_inputs function that needs it, and add a case to test_invariants.py
Changing how a key is derived in only one of the two places that derive itAn artifact that exists but is never found. Looks like "the cache does not work"regrid_item compares the two derivations explicitly; do the same for a new stage
Keeping per-file state on a reader instanceCross-contamination between granules, because one instance serves the whole collection in a processPut it on the ReaderContext returned by open()
Treating SensorWindow as a shapeA sensor-space mask trims the edge of every block instead of the detector edgeIt carries its origin; use it
Writing a cache artifact without going through write_file / write_dirA partial artifact that reads as a hit after a crashBoth commit the sidecar last, on purpose
Having a worker consult the manifest or the catalogueA run that is not reproducible, and an executor that cannot be portedWhatever it needs goes into plan.json at plan time
Changing src/stratum/regrid/ without running the hash checkGLTs built by old code, reused by new code, with no indicationSection 4
Importing stratum_emit from stratum "just for a type"The framework stops being re-targetableThe type belongs in stratum.types, or the coupling belongs in an entry point
Deleting a run directory to "start clean"Nothing, usually — but deleting {root}/cache/ discards every GLT, which is the expensive halfRun directories are disposable; the cache is not
